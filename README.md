# SensorClockViewer

This application visualizes the log data accumulated by the [SensorClock](https://github.com/yu2924/SensorClock).

- Fetch the data accumulated by SensorClock and store it in the database.
- Plot the changes over time for each sensor.
- Trim the unnecessary parts of the data.
- Extract and archive any specified range of data.

It was developed for Windows 10 or later using .NET 10 and WinUI 3, written in C#.
